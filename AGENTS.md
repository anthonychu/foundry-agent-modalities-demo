# Agent instructions

This repository demonstrates the same fictional support-triage task as a Microsoft Foundry Prompt
Agent and Hosted Agent. Preserve the comparison: Prompt keeps the policy in declarative instructions;
Hosted keeps the policy in deterministic, tested Python code.

This project was built with the microsoft-foundry skill. Before working on or answering questions
about Foundry agents, read the microsoft-foundry skill first. If you are in VS Code, read the
vscode-microsoft-foundry skill first.

## Safety and source rules

- Use current official Microsoft Learn and `microsoft-foundry/foundry-samples` patterns.
- Never commit endpoints, subscription IDs, tokens, connection strings, or customer data.
- The Contoso case and priority rubric are fictional demonstration data, not Microsoft policy.
- Do not provision or deploy into a project until its owner explicitly approves temporary resources.
- Do not turn the demo into a feature bake-off. The point is ownership, not output quality.
