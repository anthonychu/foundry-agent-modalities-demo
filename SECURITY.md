# Security

Do not report security vulnerabilities through public GitHub issues.

If the issue affects a Microsoft product or service, report it to the Microsoft Security Response
Center at <https://aka.ms/security.md/msrc/create-report>. See
<https://aka.ms/security.md> for Microsoft's coordinated vulnerability disclosure policy.

For sample-specific bugs that do not expose a security vulnerability, use the repository's normal
issue tracker.
